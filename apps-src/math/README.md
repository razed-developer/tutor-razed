# Pre-Calculus Transformations Lab

A React + Vite teaching site for:

- parent functions and relations
- graph transformations
- vertical and horizontal translations
- stretches, compressions, and reflections
- inverse graphs and equations
- composed functions
- operations on functions
- digital whiteboard work

## Whiteboard features

- freehand pen
- Shift-drag straight lines
- dedicated line tool
- eraser
- text insertion
- graph-paper toggle
- undo and redo
- clear
- save as PNG

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```
